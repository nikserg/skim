2026 年 Windows 上的 AI 邮件客户端

Skim, BYOK、本地优先、免费

Skim 是一款面向 Windows 的免费开源邮件客户端，使用原生 Rust 内核。AI 功能--草稿、润色、线程问答、整个邮箱的聊天、未读摘要--使用你的 API 密钥。粘贴 Anthropic（Claude）、OpenRouter 或任何 OpenAI 兼容端点的密钥，紫色 AI 按钮即被点亮。密钥存放于 Windows 凭据管理器；请求从你的机器直达提供商。

将 Skim 指向 Ollama、LM Studio 或 vLLM 上的本地模型--"Windows 的 AI 邮件客户端"就从不打电话回家。

Spark+（Readdle）

"用 AI 撰写"、建议、分类。邮件经由 Readdle 服务器。~5–8 USD/月。

Canary Mail

"Sidekick" 撰写、总结、回复。~20–50 USD/年。

Outlook + Copilot

Microsoft 365 Copilot 把 AI 带进 Outlook。~30 USD/用户/月。

Thunderbird + 插件

没有内置 AI，但社区插件把 ChatGPT/Claude 接入撰写窗口。

更少按钮。更少痛苦。

邮件客户端通常有两种：一种是伪装成应用的浏览器，另一种是带着 ICQ 时代气息的庞大全能套件。Skim 两者都不是。

原生，而非 Chromium

Rust 内核搭配系统 WebView2 界面——不像 Electron 那样打包整个浏览器。安装包只有几兆字节，冷启动瞬间完成，空闲内存占用很低。无需管理员权限即可安装。

我们砍掉了一半功能。故意的。

没有日历、没有联系人管理、没有规则、没有过滤器、没有稍后提醒——那些你反正从来不用的东西一概没有。更少按钮意味着更少认知负担，也就更少烦躁。需要全能套件？装 Outlook 去。

需要时，操作才出现

按钮只在有用时才出现。根本没有菜单栏。Skim 的全部工作就是在正确的时刻给出正确的操作。它做得好不好，见仁见智——不过你可以帮忙！

默认本地且私密

邮件通过 IMAP 直接同步到本地 SQLite 数据库。可离线使用，搜索即时（FTS5），每个操作立即生效并排队——网络恢复后 Skim 会自动补齐。零遥测，零肛门探针。

知道今天是星期四、还能像你一样写作的 AI

没有「Skim Pro」订阅，将来也不会有。粘贴你自己的 Anthropic（Claude）或 OpenRouter 密钥（Claude、GPT、Gemini、Grok 以及数百种其他模型）——或将 Skim 指向任意兼容 OpenAI 的端点（包括通过 Ollama、LM Studio 或 vLLM 运行的本地模型）——紫色的 ✦ 按钮便会激活。请求直接从你的机器发往服务商：没有我们的代理，也没有加价。你按成本价付给服务商，密钥存放在 Windows 凭据管理器里。没有密钥？Skim 也就是个快速的邮件客户端（是差点意思，但有何不可？）。

  • [01]

    以你的口吻起草——告诉它要说什么，就得到一封以第一人称写好的邮件。Skim 可以分析多达一百封你已发送的邮件，并像你一样写作：同样的问候语、句子长度、标点。它用发件人的语言回复，哪怕那是你不会的语言。

  • [02]

    在对话中打磨草稿——「短一点」「加个截止日期」「去掉感叹号」。每次调整都作用于当前文本，保留你没要求改动的一切。你手动编辑，AI 也会照顾到。

  • [03]

    就邮件提问——针对某封邮件或整条会话（上下文最多 25 封邮件）提问，可追问。它只根据内容回答：如果对话里没有答案，它会如实说明。

  • [04]

    与整个邮箱对话——「这个月哪些发票还没付款？」直接在命令面板里问。Skim 搜索你的邮件（FTS5/bm25），作答并以可点击的标签引用来源邮件。

  • [05]

    未读邮件的 AI 摘要——一键概括多达 20 封未读邮件：先列出需要回复的，附上截止日期和引用来源，通讯类邮件另放一边。它会把处理过的标记为已读。

  • [06]

    它了解上下文——每个提示都会带上当前日期、星期几、时间和你的时区、界面语言，以及（在需要时）整条会话。于是「回复说我周五之前能完成」会变成一个具体日期，而不是抽象说法。

常见问题

在 Windows 上更换邮件客户端之前，大家通常会问的一切。

这些都是 vibe coding 出来的吗？

当然。都 2026 年了——醒醒吧，武士！没人再手写代码了。

Skim 是免费的吗？

是的。Skim 基于 MIT 许可证，免费且开源 —— 没有订阅、无需账户、没有增值推销。AI 功能是可选的，使用你自己的 API 密钥：你直接按成本价向 AI 服务商付费。

Skim 支持哪些邮件服务商？

Gmail（一键 Google 登录或应用专用密码）、Outlook、Yahoo 和 iCloud（通过应用专用密码），以及任何支持标准 IMAP/SMTP 的邮箱。主流服务商的服务器设置会自动填充。

AI 会读取我的邮件吗？

只有在你主动要求时才会。在你粘贴自己的密钥——Anthropic、OpenRouter 或任意兼容 OpenAI 的端点（包括通过 Ollama、LM Studio 或 vLLM 运行的本地模型）——之前，AI 功能保持关闭；每个请求都从你的电脑直达服务商，没有中间服务器。密钥保存在 Windows 凭据管理器中。

Skim 能在 Windows 10 和 Windows 11 上运行吗？

可以 —— Skim 支持装有 WebView2 的 Windows 10 和 11（Windows 11 已预装）。安装包约 5 MB，按用户安装，无需管理员权限。

Skim 和 Outlook 或 Thunderbird 有什么不同？

Skim 刻意保持小巧：一款快速、键盘优先的 Windows 邮件客户端，原生 Rust 内核而非 Electron，离线优先操作、即时本地搜索，以及使用你自己密钥的 AI 副驾。没有日历、没有规则引擎、没有累赘。

我的邮件存储在本地吗？

是的。邮件通过 IMAP 直接同步到你设备上的本地 SQLite 缓存，因此 Skim 可离线使用，搜索即时完成。Skim 没有服务器，也没有任何遥测。

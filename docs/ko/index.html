버튼은 더 적게. 고통도 더 적게.

이메일 클라이언트는 보통 두 종류입니다. 앱인 척하는 브라우저이거나, ICQ 시대 감성의 괴물 같은 올인원 제품이거나. Skim은 둘 다 아닙니다.

네이티브, Chromium 아님

Rust 코어에 시스템 WebView2 UI — Electron처럼 브라우저를 통째로 넣지 않습니다. 설치 파일은 몇 메가바이트, 콜드 스타트는 즉시, 유휴 메모리도 적습니다. 관리자 권한 없이 설치됩니다.

기능의 절반을 덜어냈습니다. 일부러요.

달력 없음, 연락처 관리자 없음, 규칙 없음, 필터 없음, 미루기 없음 — 어차피 안 쓰는 것들은 전부 없습니다. 버튼이 적을수록 인지 부담이 줄고, 그만큼 짜증도 줄어듭니다. 올인원이 필요하세요? Outlook을 설치하세요.

필요할 때 동작이 나타납니다

버튼은 쓸모 있을 때만 나타납니다. 메뉴 막대는 아예 없습니다. Skim의 임무는 알맞은 동작을 알맞은 순간에 내미는 것. 얼마나 잘 해내는지는 논쟁거리지만 — 당신이 도울 수 있습니다!

기본적으로 로컬 & 프라이빗

메일은 IMAP으로 로컬 SQLite 데이터베이스에 곧장 동기화됩니다. 오프라인에서도 작동하고, 검색은 즉각적이며(FTS5), 모든 동작은 즉시 적용되어 대기열에 들어갑니다 — 네트워크가 돌아오면 Skim이 따라잡습니다. 텔레메트리 제로, 항문 탐침 제로.

>_ 단축키 하나로 뭐든지

단축키 하나로 무엇이든. 메일 검색, 어느 폴더로든 이동, 빠른 명령 실행, 그리고 메일함 전체에 대해 AI에게 질문 — 창 하나, 마우스 불필요.

「Skim Pro」 구독은 없고 앞으로도 없습니다. 본인의 Anthropic(Claude) 또는 OpenRouter 키(Claude, GPT, Gemini, Grok 등 수백 개 모델)를 붙여넣거나 Skim을 OpenAI 호환 엔드포인트(Ollama, LM Studio, vLLM로 구동하는 로컬 모델 포함)로 지정하면 보라색 ✦ 버튼이 살아납니다. 요청은 당신의 컴퓨터에서 제공업체로 곧장 갑니다: 우리 프록시도, 마진도 없습니다. 제공업체에 원가로 지불하고, 키는 Windows 자격 증명 관리자에 보관됩니다. 키가 없다고요? Skim은 그냥 빠른 이메일 클라이언트로 작동합니다(그저 그렇지만, 안 될 거 있나요?).

  • [01]

    당신의 목소리로 초안 — 무슨 말을 할지 알려주면 1인칭으로 완성된 이메일을 받습니다. Skim은 보낸 메일을 최대 100통까지 분석해 당신처럼 씁니다: 같은 인사말, 문장 길이, 문장부호. 답장은 보낸 사람의 언어로, 당신이 모르는 언어라도 씁니다.

  • [02]

    대화로 다듬는 초안 — 「더 짧게」, 「마감일 추가」, 「느낌표 빼」. 모든 수정은 현재 텍스트에 적용되며, 바꾸라고 하지 않은 건 그대로 둡니다. 직접 손보면 AI도 그것을 반영합니다.

  • [03]

    이 메일에 대해 질문 — 한 통이나 스레드 전체(최대 25통을 문맥으로)에 대해 질문하고 추가 질문도 가능합니다. 내용에서만 답합니다: 대화에 답이 없으면 없다고 말합니다.

  • [04]

    메일함 전체와 채팅 — 「이번 달 아직 미결제된 청구서는?」을 명령 팔레트에서 바로. Skim은 메일을 검색해(FTS5/bm25) 답하고, 출처 메일을 클릭 가능한 칩으로 인용합니다.

  • [05]

    안 읽은 메일 AI 요약 — 클릭 한 번으로 최대 20통의 안 읽은 메일을 요약합니다: 답장이 필요한 것부터, 마감일과 인용 출처와 함께, 뉴스레터는 한쪽으로. 처리한 것은 읽음으로 표시합니다.

  • [06]

    맥락을 압니다 — 모든 프롬프트에 현재 날짜, 요일, 시각과 당신의 시간대, 인터페이스 언어, 그리고 필요할 때는 스레드 전체가 실립니다. 그래서 「금요일까지 끝낼 수 있다고 답장해」가 추상이 아니라 구체적인 날짜가 됩니다.

몇 초 만에 설치

최신 설치 파일을 다운로드하세요 — .exe(NSIS)는 관리자 권한 없이 사용자별로 설치되고, 관리형 환경을 위한 .msi도 함께 제공됩니다. WebView2가 포함된 Windows 10/11이 필요합니다(Windows 11에는 기본 설치됨).

패키지 관리자를 선호하신다면 scoop bucket add skim https://github.com/nikserg/skim 후 scoop install skim/skim.

자주 묻는 질문

Windows에서 이메일 클라이언트를 바꾸기 전에 흔히 묻는 것들.

이거 다 바이브 코딩한 거예요?

당연하죠. 2026년입니다 — 일어나요, 사무라이! 이제 아무도 손으로 코드 안 짜요.

Skim은 무료인가요?

네. Skim은 MIT 라이선스의 무료 오픈소스입니다 — 구독도, 계정도, 추가 판매도 없습니다. AI 기능은 선택 사항이며 본인의 API 키를 사용하므로, AI 제공업체에 원가 그대로 직접 지불합니다.

어떤 이메일 서비스를 지원하나요?

Gmail(원클릭 Google 로그인 또는 앱 비밀번호), 앱 비밀번호를 통한 Outlook·Yahoo·iCloud, 그리고 표준 IMAP/SMTP를 쓰는 모든 메일함을 지원합니다. 주요 서비스는 서버 설정이 자동으로 채워집니다.

AI가 내 메일을 읽나요?

요청할 때만 읽습니다. 본인의 키(Anthropic, OpenRouter 또는 OpenAI 호환 엔드포인트 — Ollama, LM Studio, vLLM로 구동하는 로컬 모델 포함)를 붙여넣기 전까지 AI 기능은 꺼져 있으며, 모든 요청은 내 컴퓨터에서 제공업체로 직접 전송됩니다 — 중간 서버는 없습니다. 키는 Windows 자격 증명 관리자에 저장됩니다.

Windows 10과 Windows 11에서 실행되나요?

네 — Skim은 WebView2가 있는 Windows 10/11을 지원합니다(Windows 11에는 기본 설치). 설치 파일은 약 5 MB이며 사용자별로 설치되어 관리자 권한이 필요 없습니다.

Outlook이나 Thunderbird와 무엇이 다른가요?

Skim은 의도적으로 작게 만들어졌습니다. Electron 대신 네이티브 Rust 코어를 쓰는 빠르고 키보드 중심적인 Windows 이메일 클라이언트로, 오프라인 우선 동작, 즉각적인 로컬 검색, 내 키로 동작하는 AI 코파일럿을 갖췄습니다. 캘린더도, 규칙 엔진도, 군더더기도 없습니다.

내 메일은 로컬에 저장되나요?

네. 메일은 IMAP을 통해 기기의 로컬 SQLite 캐시로 바로 동기화되므로 Skim은 오프라인에서도 동작하고 검색은 즉각적입니다. Skim 서버는 없고 텔레메트리도 전혀 없습니다.

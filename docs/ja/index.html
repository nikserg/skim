ボタンは少なく。痛みも少なく。

メールクライアントはたいてい二種類です。アプリのふりをしたブラウザか、ICQ 時代の空気をまとった怪物級の全部入りスイートか。Skim はそのどちらでもありません。

ネイティブ、Chromium ではない

Rust コアにシステムの WebView2 UI——Electron のようにブラウザを丸ごと同梱しません。インストーラーは数メガバイト、コールドスタートは一瞬、待機時のメモリも控えめ。管理者権限なしでインストールできます。

機能を半分削りました。わざとです。

カレンダーなし、連絡先マネージャーなし、ルールなし、フィルターなし、スヌーズなし——どうせ使わないものは一切なし。ボタンが少ないほど認知の負荷が減り、イライラも減ります。全部入りが必要？ Outlook をどうぞ。

必要なときに操作が現れる

ボタンは役に立つときだけ現れます。メニューバーはそもそもありません。Skim の仕事は、正しい操作を正しい瞬間に差し出すこと。それがどれだけうまくいっているかは議論の余地あり——でもあなたが手伝えます！

既定でローカル＆プライベート

メールは IMAP でローカルの SQLite データベースへ直接同期します。オフラインでも動き、検索は一瞬（FTS5）、あらゆる操作は即座に適用されてキューに入り——ネットワークが戻ると Skim が追いつきます。テレメトリーはゼロ、肛門プローブもゼロ。

今日が木曜日だと知っていて、あなたのように書く AI

「Skim Pro」のサブスクは存在せず、これからも存在しません。自分の Anthropic（Claude）または OpenRouter の鍵（Claude、GPT、Gemini、Grok ほか数百のモデル）を貼り付けるか、Skim を任意の OpenAI 互換エンドポイント（Ollama・LM Studio・vLLM で動かすローカルモデルを含む）に向ければ、紫の ✦ ボタンが動き出します。リクエストはあなたのマシンからプロバイダーへ直行——こちらのプロキシも上乗せもありません。プロバイダーには原価で支払い、鍵は Windows 資格情報マネージャーに保管されます。鍵がない？ Skim は単に高速なメールクライアントとして動きます（まあまあですが、悪くないでしょう？）。

  • [01]

    あなたの声で下書き——何を言うか伝えれば、一人称で仕上がったメールが返ってきます。Skim は送信済みメールを最大 100 通まで分析し、あなたの書き方——同じ挨拶、文の長さ、句読点——で書けます。返信は差出人の言語で、あなたが話せない言語でも大丈夫。

  • [02]

    対話で磨く下書き——「もっと短く」「締め切りを追加」「感嘆符を外して」。どの微調整も現在のテキストに適用され、変えてと頼んでいない部分はそのまま。手で編集すれば、AI はそれも踏まえます。

  • [03]

    このメールについて質問——1 通のメールやスレッド全体（最大 25 通を文脈に）について質問でき、追加質問も可能。答えは内容のみから：会話に答えがなければ、そう言います。

  • [04]

    メールボックス全体とチャット——「今月まだ支払われていない請求書は？」をコマンドパレットで直接。Skim はメールを検索し（FTS5/bm25）、答えを返し、出典のメールをクリックできるチップとして示します。

  • [05]

    未読の AI まとめ——ワンクリックで最大 20 通の未読を要約：まず返信が必要なもの、締め切りと出典つきで、ニュースレターは脇へ。処理したものは既読にします。

  • [06]

    文脈を知っている——どのプロンプトにも、現在の日付・曜日・時刻とあなたのタイムゾーン、UI の言語、そして必要な場合はスレッド全体が含まれます。だから「金曜までに間に合うと返信して」が抽象ではなく具体的な日付になります。

よくある質問

Windows のメールクライアントを乗り換える前に、よく聞かれることをまとめました。

これ全部バイブコーディング？

もちろん。2026年だぞ——起きろ、サムライ！もう誰も手でコードを書かない。

Skim は無料ですか？

はい。Skim は MIT ライセンスの無料オープンソースです。サブスクリプションもアカウントもアップセルもありません。AI 機能はオプションで、あなた自身の API キーを使用します。AI プロバイダーへは原価のまま直接支払います。

どのメールプロバイダーに対応していますか？

Gmail（ワンクリックの Google サインインまたはアプリパスワード）、アプリパスワード経由の Outlook・Yahoo・iCloud、そして標準の IMAP/SMTP に対応するあらゆるメールボックス。大手プロバイダーはサーバー設定が自動入力されます。

AI は私のメールを読みますか？

あなたが求めたときだけです。自分のキー（Anthropic、OpenRouter、または任意の OpenAI 互換エンドポイント——Ollama・LM Studio・vLLM で動かすローカルモデルを含む）を貼り付けるまで AI 機能はオフのままで、すべてのリクエストはあなたの PC からプロバイダーへ直接送信されます。中間サーバーはありません。キーは Windows 資格情報マネージャーに保存されます。

Skim は Windows 10 と Windows 11 で動きますか？

はい。Skim は WebView2 を備えた Windows 10 / 11 に対応しています（Windows 11 にはプリインストール済み）。インストーラーは約 5 MB、ユーザー単位でインストールされ、管理者権限は不要です。

Outlook や Thunderbird と何が違いますか？

Skim は意図的に小さく作られています。Electron ではなくネイティブ Rust コアを持つ、高速でキーボードファーストな Windows メールクライアント。オフラインファーストの操作、瞬時のローカル検索、そして自分のキーで動く AI コパイロット。カレンダーもルールエンジンも余計なものもありません。

メールはローカルに保存されますか？

はい。メールは IMAP 経由でデバイス上のローカル SQLite キャッシュに直接同期されるため、Skim はオフラインでも動作し、検索も一瞬です。Skim のサーバーは存在せず、テレメトリーもゼロです。
